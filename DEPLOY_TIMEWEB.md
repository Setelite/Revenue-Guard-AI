# Как запустить сервер Revenue Guard AI в Timeweb Cloud

Приложение для iPhone остаётся на GitHub Pages: https://setelite.github.io/Revenue-Guard-AI/

## 1. Создать сервер

В Timeweb Cloud → **App Platform** → **Создать** → **Backend**. Подключите GitHub репозиторий **Setelite/Revenue-Guard-AI**, ветка `main`.

- Фреймворк: **FastAPI**.
- Python: **3.11** или новее.
- Файл запуска: **main.py** (уже добавлен), объект приложения `app`.
- Команда сборки: `pip install -r requirements.txt`.
- Команда запуска (если запрашивает): `uvicorn main:app --host 0.0.0.0`.
- Регион: российский дата-центр.
- Тариф: минимальный доступный для тестирования API; проверьте ежемесячную цену перед оплатой.

## 2. В расширенных настройках → Переменные

Укажите следующие переменные **через приватный интерфейс Timeweb**, а не через GitHub:

| Имя | Значение |
| --- | --- |
| `AI_PROVIDER` | `cloudru` |
| `CLOUDRU_MODEL` | `ai-sage/GigaChat3-10B-A1.8B` |
| `CLOUDRU_API_KEY` | Key Secret из Cloud.ru (никому не пересылайте) |
| `RG_DEMO_ACCESS_TOKEN` | Свой **отдельный** случайный код не короче 24 символов |
| `RG_ALLOWED_ORIGINS` | `https://setelite.github.io` |

`RG_DEMO_ACCESS_TOKEN` не должен совпадать с API-ключом Cloud.ru. Для тестов используйте только вымышленные данные салона и не публикуйте в интернете код доступа.

## 3. Запустить

Включите автодеплой, нажмите «Заказать», после успешной сборки скопируйте технический адрес приложения **с HTTPS**. В некоторых настройках Timeweb команда запуска может быть автоматически определена из `main.py`.

## 4. Связать с iPhone

Откройте **https://setelite.github.io/Revenue-Guard-AI/** → **Бизнес → Подключение ИИ**:
- HTTPS-адрес сервера: адрес, выданный Timeweb.
- Код доступа: ровно `RG_DEMO_ACCESS_TOKEN` (НЕ Cloud.ru Key Secret).
- Нажмите «Проверить подключение». Проверка статуса показывает наличие ключа на сервере, но **не тестирует реальные вызовы** к модели.
- Вернитесь на главный экран и создайте тестовую задачу «Привлечь клиентов на свободные часы завтра без скидок». В случае ошибки скопируйте текст ошибки без секретов.

## Безопасность

Это прототип с единым кодом доступа, **не** готовый многопользовательский SaaS. Не используйте реальные имена, номера, адреса и переписки клиентов. Автопубликация рекламы и автоплатежи отключены.
