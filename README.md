# Revenue Guard AI — MVP 1.0

Мобильный демонстратор **ИИ-коммерческого директора**. Не CRM. Начинается с коммерческой цели владельца бизнеса, предлагает три стратегии, готовит текст публикации и сторис, требует подтверждения владельца, фиксирует отдельно фактические оплаты.

## Возможности

- **5 экранов:** главная, задачи, креативная студия, продажи, профиль бизнеса.
- **Голосовой ввод:** через Web Speech API браузера, если поддерживается. Также работает ввод с клавиатуры. Транскрипт проверяет пользователь перед отправкой.
- **Генерация трёх предложений:** локальные шаблоны в автономном режиме. **Настоящий ИИ** доступен через опциональный Python-сервер и Yandex AI Studio с API-ключом.
- **Креативы:** редактирование заголовка, описания, текста поста, канала; экспорт сторис **1080×1920 PNG**. Это постер на основе шаблона, а не генерация фотореалистичных изображений нейросетью.
- **Согласование:** черновик → на согласовании → одобрено → размещено (вручную). Никакой настоящей публикации или платежей приложение не производит.
- **Учёт продаж:** вручную вносится реально оплаченный визит, CSV-экспорт; данные не доказывают причинную роль кампании.
- **Сохранение:** localStorage в одном браузере на одном устройстве. Кнопки резервной копии JSON и сброса.
- **PWA:** можно добавить ярлык на домашний экран. Для надёжного офлайн-режима без предварительной загрузки достаточно открыть статическую HTML-страницу; отдельный сервис-воркер не включён.

## Самый быстрый запуск — демонстрация

Откройте `static/index.html` двойным щелчком. Для проверки голосового ввода предпочтителен локальный HTTPS/localhost сервер: браузер может не разрешать микрофон при открытии `file://`.

Для локального HTTP (без ИИ):

```sh
cd Revenue_Guard_AI_MVP_1_0/static
python -m http.server 8000
```

Откройте http://localhost:8000 . В этом режиме три предложения генерируются **детерминированно**, без обращений к внешним ИИ.

## Настоящий ИИ (Yandex AI Studio)

1. Создайте API-ключ и каталог с правами для моделей в Yandex AI Studio. Это платный/тарифицируемый внешний сервис.
2. В корне проекта (рядом с `server.py`) создайте `.env` по образцу `.env.example`, задав `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`. Не размещайте `.env` в публичном GitHub.
3. В терминале:

```sh
cd Revenue_Guard_AI_MVP_1_0
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

4. Откройте http://localhost:8000 . При корректной настройке в верхнем статусе появится **«ИИ подключен»**. По нажатию «Создать кампанию» сервер отправляет бизнес-цель и общедоступный прайс в Yandex AI Studio, проверяет, что ответ содержит ровно три оффера, и возвращает в интерфейс. Если провайдер недоступен, интерфейс **открыто сообщает**, что перешёл на локальные шаблоны.
5. **Не вводите имена, телефоны, сообщения клиентов и иную персональную информацию в задачи** — демонстратор не подготовлен для её обработки.

Документация API и заголовков аутентификации: https://aistudio.yandex.ru/en/docs/ai-studio/operations/generation/completions-basic

## 2-минутный тест пользовательского пути

1. Главная → нажать быстрый сценарий «Заполнить свободные окна» → «Создать кампанию».
2. Задачи → выбрать один из 3 офферов → «Открыть креатив».
3. Креатив → изменить заголовок → «Сохранить» → «PNG 1080×1920».
4. Задачи → «Передать на согласование» → «Подтвердить кампанию» → «Отметить размещение». **Все подтверждения демонстрационные**.
5. Продажи → добавить один визит с подтверждением фактической оплаты → проверить результат и выгрузить CSV.
6. Бизнес → отредактировать название и цены. Следующие кампании используют обновлённый прайс.

## Что НЕ является готовым к коммерческому запуску

- Нет пользователей, сервера клиентских данных, авторизации, отдельного доступа салонов, журналирования, защиты API от публичного злоупотребления, системы резервного копирования на сервере, контроля стоимости токенов.
- Данные в localStorage доступны на устройстве и стираются при очистке браузера. Используйте только вымышленные тестовые данные.
- Нет подключения к CRM, звонкам, рекламным кабинетам, платежам и аналитике на реальных источниках.
- Голосовой ввод использует Web Speech API. **Поддержка браузеров ограничена**. В Chrome распознавание может происходить через внешний сервер браузерного поставщика: речь не всегда обрабатывается на устройстве. См. https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition . Для работы с реальными персональными данными нужно отдельно проектировать безопасное распознавание речи.
- Нет автоматически измеряемого прироста продаж; только учёт сумм, указанных оператором.
- Юридическая готовность продукта (152-ФЗ, согласия, реклама, маркировка) не установлена. Для реального пилота потребуется техническая и правовая подготовка.
- API сервер предназначен **для localhost**, не для размещения в публичном интернете. Не публикуйте до добавления авторизации, rate limiting, секретного хранилища и проверок.
