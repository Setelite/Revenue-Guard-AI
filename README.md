# Revenue Guard AI — пилот с Yandex AI Studio

Ветка main содержит светлый мобильный интерфейс и сервер FastAPI.

## Что уже сделано
- На GitHub Pages работает локальный демонстратор, без обращения к ИИ.
- В «Бизнес → Подключение ИИ» можно указать HTTPS-адрес собственного сервера и код доступа.
- При подключённом сервере задача отправляется в Yandex AI Studio, а модель возвращает три **разных** коммерческих предложения по информации владельца. Интерфейс показывает, что предложения получены от ИИ.
- Если сервер недоступен или ответ невалидный, **автоматической подмены шаблонами нет**: пользователь видит ошибку.
- Ключ Yandex хранится **только на сервере**, не в GitHub Pages.
- Согласование, сторис и учёт оплат остаются демонстрационными и локальными. Никаких реальных публикаций и платежей.

## Как получить реальный ИИ (нужен свой сервер)
1. В [Yandex AI Studio](https://aistudio.yandex.ru/) создайте каталог и API-ключ сервисного аккаунта с правами работы с моделями. Генерация тарифицируется провайдером.
2. Арендуйте защищённый сервер с HTTPS и Python 3.11+. GitHub Pages исполняет только статические файлы и не запустит Python.
3. Скопируйте файлы этого репозитория на сервер (или разверните с GitHub). Создайте отдельный **непубличный** файл `.env` по образцу `.env.example`; укажите `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `RG_DEMO_ACCESS_TOKEN` (не менее 24 случайных символов).
4. Запустите `python -m pip install -r requirements.txt`, затем `uvicorn server:app --host 127.0.0.1 --port 8000`. Перед внешним доступом установите HTTPS reverse proxy (например, Caddy или nginx) и ограничьте доступ к демосерверу. Не открывайте напрямую порт 8000 в Интернет.
5. На iPhone: Revenue Guard → «Бизнес» → «Подключение ИИ». Укажите HTTPS-адрес сервера и **код доступа к демо**, НЕ Yandex API key. Нажмите «Проверить подключение».
6. Создайте текстовую задачу. Если внешняя модель ещё не была действительно проверена, первым тестом станет реальная генерация.

## API
- `GET /api/status` — проверяет настройку переменных и код доступа; **не** выполняет тестовый запрос к модели.
- `POST /api/generate` — вызывает Yandex AI Studio и проверяет структуру результата.
- Заголовок: `X-Demo-Token` с отдельным кодом доступа; `Authorization: Api-Key ...` формируется на backend и никогда не попадает во фронтенд.
- Модель по умолчанию: `gpt://<FOLDER_ID>/yandexgpt-5.1`.
- Аудио использует браузерный SpeechRecognition, **это пока не SpeechKit**.

Документация: https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-basic

## Ограничения
Это **пилот, не production SaaS**: общий демо-код вместо личных аккаунтов, локальное хранение задач, упрощённый лимит вызовов на процесс, нет полноценного аудита и подтверждённого attribution. Не вводите персональные данные клиентов. Для реальной эксплуатации нужны аккаунты и роли, централизованное хранилище, квоты и мониторинг затрат, резервирование, юридическая проверка.
